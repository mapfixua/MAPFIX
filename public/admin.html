Порожньо

Імпорт з Google Maps (Gemini + каталог Mapfix)

Лише для адміна. Натисніть Виділити область і протягніть прямокутник на карті. Система шукає заклади Google Maps у цій зоні за усіма категоріями, підкатегоріями та послугами Mapfix. Gemini пропонує класифікацію — у списку перевірки можна змінити категорію, підкатегорію й послуги, потім підтвердити імпорт.

Область не виділено

Підтягнути відгуки Google

Для точок, затягнутих областю / населеним пунктом, є рейтинг, але тексти відгуків часто порожні. Кнопка методично знаходить кожен заклад у Google Maps і записує відгуки (Places API віддає до 5 текстів на точку — як при імпорті з посилання).

Кандидати області

Імпорт надавачів (Google / OSM)

1) Заповніть форму → Перевірити перед імпортом. 2) Зніміть галочки з некоректних точок. 3) Імпортуйте лише вибрані.

Перевірка точок

Імпорт за посиланням Google Maps

Вставте коротке посилання на кшталт https://maps.app.goo.gl/.... AI запропонує категорію Mapfix. Без API система безкоштовно імпортує назву й координати; Назву й координати витягнемо з посилання навіть без Google Places API; з ключем Places також підтягнуться телефон, рейтинг, відгуки, сайт і графік.

Імпорт з Telegram-груп

Бот Telegram не читає довільні групи — лише чати, куди його додано (зробіть бота адміном і вимкніть Privacy Mode в @BotFather). Найпростіший шлях: скопіюйте оголошення майстрів або завантажте JSON-експорт з Telegram Desktop («Експорт історії чату» → result.json). Вставлені оголошення розділяйте порожнім рядком. Gemini підбере категорію, підкатегорію й послуги Mapfix.

Глобальний каталог

Редагуйте дерево нижче: подвійний клік — перейменувати, перетягніть послугу на іншу підкатегорію, кнопки — видалити. Форми справа лише для швидкого додавання. Зміни одразу на карті й у реєстрації майстрів.

Поточний каталог

Подвійний клік по назві змінює її. Послугу можна перетягнути в іншу підкатегорію. Підказки при введенні пропонують уже наявні назви з каталогу.

Нова локація

Клікніть на карту або перетягніть маркер — адреса заповниться автоматично. Поле адреси можна відредагувати вручну.

Оберіть точку на карті

1) Оберіть категорію. 2) Поставте галочки на потрібні підкатегорії. 3) Позначте послуги для прайсу або додайте свою нижче. Почніть вводити назву — з’являться підказки з каталогу.

Спочатку оберіть категорію

Введіть кілька літер. Якщо підкатегорія вже є в каталозі — оберіть її з підказок. Якщо немає — натисніть «Додати свою».

Спочатку оберіть підкатегорії

Почніть вводити назву — підставимо існуючу з каталогу. Нову послугу можна додати зі своєю ціною.

Фото точки

Фото доступні на Pro / у пробному періоді. Кожне до 5 МБ (JPEG / PNG / WebP).

Поточний прайс точки

Позначте послуги вище, скачайте шаблон Excel (колонки: Підкатегорія, Послуга, Ціна послуги грн), внесіть ціни в колонку C і імпортуйте файл назад.
